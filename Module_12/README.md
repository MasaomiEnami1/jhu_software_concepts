# Module 10: Graduate Admissions Neural Network

## What the program does
This program implements a two-layer neural network from scratch using purely NumPy. It predicts whether a graduate school applicant will be accepted or rejected based on their GPA, GRE scores, program type (Master's vs PhD), and citizenship status. The program handles data loading, strict train/test splitting to prevent data leakage, matrix-based forward and backward propagation (using Mean Squared Error and Sigmoid activations), and evaluates the model against artificial applicant profiles.

## What files are included
* `neural_network.py`: The complete python script containing all logic, preprocessing, network classes, and execution code.
* `README.md`: This file, explaining the module.
* `mse_curve.png`: A line graph displaying the Training MSE and Testing MSE across epochs, generated by the script.
* `training.log`: A text log of the console output generated during training, capturing early stopping and final evaluation metrics.
* `writeup.pdf`: A document containing the final analysis, graphs, and reflections on the model's performance.
* `cleaned_gradcafe.json`: The dataset (required to run the code).

## How to run the code
1. Ensure Python 3.10+ is installed along with the `pandas`, `numpy`, `matplotlib`, and `scikit-learn` libraries.
2. Place `cleaned_gradcafe.json` in the exact same directory as the script.
3. Open a terminal and execute the file:
   `python neural_network.py`

## What outputs are produced
* Console printouts detailing the dataset size, preprocessing steps, and training progress (every 100 epochs).
* A file named `training.log` capturing the full console output.
* A file named `mse_curve.png` representing the training vs testing error over time.
