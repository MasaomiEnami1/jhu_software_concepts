# Module 11: KMeans MLOps Pipeline

## Description
This project implements a basic MLOps workflow using **MLflow** to track a KMeans clustering model trained on the GradCafe dataset.

### Contents
- `kmeans_mlops_pipeline.py`: The main Python script that handles data cleaning, TfidfVectorization, PCA (75 components), and KMeans clustering.
- `cleaned_gradcafe.json`: The source dataset.
- `requirements.txt`: List of dependencies required to run the pipeline.
- `screenshots/`: Contains visual proof of successful MLflow tracking.
